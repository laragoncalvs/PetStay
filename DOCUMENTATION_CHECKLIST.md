## 🚀 Como Usar a Documentação

### Sou um novo desenvolvedor
1. Leia **README.md** primeiro
2. Escolha sua plataforma em **SETUP.md**
3. Execute o script de setup apropriado
4. Consulte **TROUBLESHOOTING.md** se tiver problemas

### Vou contribuir com código
1. Leia **CONTRIBUTING.md**
2. Siga os padrões de código
3. Faça PR com descrição clara

### Estou com problema
1. Procure em **TROUBLESHOOTING.md**
2. Se não resolver, abra issue no GitHub
3. Descreva o erro exatamente como em TROUBLESHOOTING

### Quero entender a arquitetura
1. Leia seção de "Estrutura do Projeto" em **README.md**
2. Consulte "Documentação Técnica" em **DOCS.md**
3. Revise código seguindo as convenções em **CONTRIBUTING.md**

## 🎯 Fluxo de Setup Rápido

### Windows
```
1. Executar: setup.bat
2. Seguir as instruções no terminal
3. Acessar: http://localhost:5000
```

### Linux/macOS
```
1. Executar: bash setup.sh
2. Seguir as instruções no terminal
3. Acessar: http://localhost:5000
```

### Docker
```
1. docker-compose up
2. Acessar: http://localhost:8080
```
